The card turns itself into a claim code. The desk scans it and checks all six signatures in well under a second — the one job an eyeball can't do.
Spent once
Every accepted stamp goes on the desk's spent list. A second claim, a shared card, a replayed screenshot — all the same rejection.
A–M / N–Z
Two desks, no server between them: split the queue alphabetically and a repeat claim always comes back to the desk that already spent it.
And the card visibly burns — watermarked, greyed, done at 17:42. Most double claims at real events are honest confusion, not fraud.
Before you ask
What we don't defend against
01
The live relay
A friend on a video call, holding the stall's screen up for you. No optical scheme survives it. Proximity hardware would fix it and cost us every phone that lacks it.
02
A wound-back clock
Offline means your own phone judges whether a code is fresh. The floor: you still need a real signed frame from that stall, so somebody was there.
03
A stall stamping absent friends
An authorised stall can grant its own stamp to anyone. Capped at one each — a full card still needs every stall in on it.
04
A dead battery
A stall screen at full brightness for four hours is the real failure mode, not fraud. Bring power banks. Paper never needed charging.
Every one of these is cheaper to accept than to fix, because the prize is a mug. Guard the threshold, not the theory.

Deliberately boring tech
SHELL
Static PWA
One HTML bundle on a CDN. Service worker caches it, so the hall's dead wifi doesn't matter.
IDENTITY
WebCrypto Ed25519
Non-extractable keypair in IndexedDB. The browser won't hand out the private half, even to our own code.
CODE ON SCREEN
Signed QR frame
stall · round nonce · frame counter, signed by the stall's own bound key and chained to the event key. Redrawn every 8s by a local timer.
CAMERA
BarcodeDetector
Native decode where it exists, a small WASM fallback where it doesn't. No upload, ever.
THE CARD
Signed receipts
Each stamp is kept as the stall's own signature. Anyone can verify it later — and the desk spends each one once.
EXPIRY
Event key with an end time
Past it, nothing validates and the store self-wipes. Expiry is a property of the crypto, not a cleanup job.
The event itself is a static signed JSON — a file, not a record in a database. That single choice is what removes the server, the bill and the breach surface all at once.
